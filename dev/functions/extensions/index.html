Base.isless — Method
Base.isless(a::PauliStr, b::PauliStr) -> Bool

Compare two PauliStr under a deterministic total order consistent with ==, and return whether a orders strictly before b. Four attributes are compared in the following order based on their priorities (with the first mismatched attribute deciding the result):

  1. Explicit site count: evaluated via countSites, in ascending order.
  2. Pauli weight: evaluated via countWeight, in ascending order.
  3. Operator content: comparison of the highest-indexed site where a and b carry different single-site operators, which follows the value order of PauliSym: symI, symZ, symX, symY.
  4. Phase: comparison of the Z₄ exponent of .phase::PhaseFactor such that all possible phase values follow the order: +1, +im, -1, -im.

Every attribute is defined purely in terms of the operator content of each compared string regardless of the underlying storage buffers' word size (8*sizeof(UInt)). This order underlies the canonical term order of PauliSum.

Examples

julia> pauli"II" < pauli"ZI" < pauli"XI" < pauli"IZ" < pauli"IX" < pauli"XX"
true

julia> pauli"X" < PhaseFactor(1) * pauli"X" < PhaseFactor(2) * pauli"X"
true

Base.show — Method
Base.show(io::IO, op::PauliStr) -> Nothing

Print the output String from toString(op::PauliStr) to io. When io carries the IOContext property :limit=>true (i.e., true === get(io, :limit, false)), e.g., the REPL's default display buffer, and countWeight(op)> 20, only the first and last 9 non-identity single-site operators are printed, with the omitted operators replaced by " … ". Otherwise, the complete string is always printed (in the default format).

Base.show — Method
Base.show(io::IO, ::MIME"text/plain", op::PauliStr) -> Nothing

Print the rich display of op::PauliStr to io: the printed output of show(io, op), followed by the annotation " ($n sites)" with n=countSites(op), whenever n > 1. When io carries the IOContext property :compact=>true, the annotation is omitted and the display output falls back to show(io, op).
