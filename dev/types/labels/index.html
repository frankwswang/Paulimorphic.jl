Paulimorphic.SignedReal — Type
SignedReal

The (type) union of AbstractFloat, Signed, and Rational{<:Signed}. It is a type alias for the real-number types whose instances are closed under negation (x -> -x). Hence, Bool, Unsigned, and Rational{<:Unsigned} are excluded.

Paulimorphic.PairedOrder — Type
PairedOrder <: Paulimorphic.StructuredType

The singleton format tag for the operator string ordering in which each particle's creation-annihilation operator pair stays adjacent:

\[\hat{c}_{i_1} \hat{a}_{j_1} \, \hat{c}_{i_2} \hat{a}_{j_2} \cdots \hat{c}_{i_N} \hat{a}_{j_N},\]

where $\hat{c}_p = \hat{a}_p^\dagger$ for any mode $p$; $i_k$ and $j_k$ ($1 \le k \le N$) are the modes of the creation and annihilation operators associated with the $k$-th particle, respectively. The indexing layout of any associated coefficient tensor inte that matches this operator-string ordering is named the index-pair layout:

\[\mathtt{inte}[c_1, a_1, \ldots, c_N, a_N] \leftrightarrow \hat{c}_{i_1} \hat{a}_{j_1} \, \cdots \hat{c}_{i_N} \hat{a}_{j_N},\]

where the value of $c_k$ (or $a_k$) labels the mode $i_k$ (or $j_k$).

Paulimorphic.NormalOrder — Type
NormalOrder <: Paulimorphic.StructuredType

The singleton format tag for the normal ordering of a given operator string, which places every creation operator to the left of every annihilation operator:

\[\hat{c}_{i_1} \hat{c}_{i_2} \cdots \hat{c}_{i_N} \, \hat{a}_{j_N} \cdots \hat{a}_{j_2} \hat{a}_{j_1},\]

where $\hat{c}_p = \hat{a}_p^\dagger$ for any mode $p$; $i_k$ and $j_k$ ($1 \le k \le N$) are the modes of the creation and annihilation operators of the $k$-th particle, respectively.

Paulimorphic.NBodyOrdering — Type
NBodyOrdering

The (type) union of PairedOrder and NormalOrder. It is a type alias for the operator orderings supported by functions such as genNBodyOperatorSum and encodeElecHam (as the type constraint for argument format).
